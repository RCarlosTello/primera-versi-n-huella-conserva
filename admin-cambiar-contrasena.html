📋 Pasos para aplicar el cambio:

  2. Abre public/data/_collab_raw.json
  3. Busca al colaborador por su correo
  4. Reemplaza el valor de "password_hash" con el hash generado
  5. Guarda el archivo y ejecuta npm run build
  6. Redespliega: npx wrangler pages deploy dist --project-name=huella-v1
